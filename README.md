# Analytics
# Email Activity Analysis (SQL, BigQuery)

## Project Description
Analysis of user account creation dynamics, email activity 
(sent, opened, clicked), and behavior segmentation by country, 
send interval, verification status, and subscription status.

## Goals
- Track email engagement metrics (sent, open, click rates)
- Compare activity across countries
- Identify top-10 key markets by account count and email volume
- Segment users by verification and subscription status

## Tools
- SQL (BigQuery)
- Looker Studio (visualization)
